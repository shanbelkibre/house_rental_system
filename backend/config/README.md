# Config

- [backend/config/app.php](backend/config/app.php): Core application settings like name, env, debug, locale, and keys.
- [backend/config/auth.php](backend/config/auth.php): Auth guards, providers, and password reset configuration.
- [backend/config/cache.php](backend/config/cache.php): Cache store configuration and prefixes.
- [backend/config/cors.php](backend/config/cors.php): CORS policy for API and Sanctum endpoints.
- [backend/config/database.php](backend/config/database.php): Database connections, migrations table, and Redis settings.
- [backend/config/filesystems.php](backend/config/filesystems.php): Local and public storage disks and symbolic links.
- [backend/config/logging.php](backend/config/logging.php): Log channels and log levels.
- [backend/config/mail.php](backend/config/mail.php): Mailer settings and default sender.
- [backend/config/queue.php](backend/config/queue.php): Queue connections, batching, and failed job storage.
- [backend/config/sanctum.php](backend/config/sanctum.php): Sanctum stateful domains, guards, and middleware.
- [backend/config/services.php](backend/config/services.php): Third-party service credentials placeholders.
- [backend/config/session.php](backend/config/session.php): Session driver, cookie, and storage settings.
